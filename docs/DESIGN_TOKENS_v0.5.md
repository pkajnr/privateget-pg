# PrivateGet PG visual system

Inspired by modern cloud-console design patterns, without AWS logos or trademarks.

| Token | Color | Application |
| --- | --- | --- |
| Background | `#0B1523` | Base screens |
| Surface | `#17283B` | Cards and panels |
| Input | `#0E2032` | Text fields, read-only codes |
| Stroke | `#324457` | Subtle borders |
| Orange | `#FFA51F` | Primary CTA, waiting statuses |
| Teal | `#54D7B2` | Connected statuses |
| Danger | `#FF8990` | Error and destructive actions |
| Muted | `#AFBDCB` | Helper text |
| White | `#F3F7FC` | Headings and primary text |

## UI language

Use **Start a private chat**, **Create invitation**, **Join a conversation**, **Your contact**, **You**, **Contact**, **Connection request**, **End conversation**. Do not expose role identifiers (A/B) in user-facing copy. The A/B roles may remain in internal cryptographic derivation until protocol replacement.
